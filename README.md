# Amazon CloudSearch API

Amazon CloudSearch is a managed service in the AWS Cloud that makes it simple and cost-effective to set up, manage, and scale a search solution for your website or application, supporting full-text search, faceting, highlighting, autocomplete, and geospatial search.

## APIs

- **Amazon CloudSearch API** - API for creating, configuring, and managing search domains. Supports defining index fields, configuring scaling options, managing access policies, uploading documents, and running search queries with full-text search, faceting, filtering, and highlighting capabilities.
